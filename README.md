# Sample Poetry Collection

A collection of poems in markdown format.

## AI Guidelines

### Purpose

This repository serves as a curated collection of poetry. The following guidelines outline how AI tools and contributors should interact with this project.

### Content Guidelines

- All poems must be properly attributed to their original authors.
- Maintain accurate formatting and line breaks as intended by the poet.
- Do not use AI to generate poems and attribute them to real authors.
- AI-assisted contributions (such as translations or summaries) must be clearly labeled as such.

### AI Usage Policy

1. **Attribution**: AI-generated or AI-assisted content must be explicitly marked with a note indicating the tool used.
2. **Accuracy**: Do not rely solely on AI for verifying authorship, dates, or historical context of poems. Cross-reference with reputable literary sources.
3. **Respect for Original Work**: AI should not be used to modify, paraphrase, or rewrite poems in ways that misrepresent the original author's intent.
4. **Transparency**: If AI is used in any part of the contribution process (formatting, translation, metadata), disclose this in the pull request description.
5. **Review Process**: All AI-assisted contributions undergo the same review standards as human contributions.

### Contributing

1. Fork the repository and create a feature branch.
2. Add your poem as a new markdown file with proper attribution.
3. If AI tools were used in any capacity, note this in your PR description.
4. Submit a pull request targeting the `main` branch.
